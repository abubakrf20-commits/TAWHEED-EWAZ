# ارسال اعلان پوش به کاربران — راهنمای مدیر

هر نصب اپ (اندروید/iOS) که حداقل یک‌بار باز شده باشد در موضوع **`all`**
مشترک است. ارسال به این موضوع یعنی «برای همه برسد».

سه راه دارید:

---

## راه ۰ — پنجرهٔ ارسال محلی (پیشنهادی: فقط عنوان و متن، دکمهٔ ارسال)

ساده‌ترین راه: از پوشهٔ برنامه، **`start-push.bat`** را دوبار کلیک کنید
(یا در ترمینال: `node tools/fcm_server.mjs`).

مرورگر به‌صورت خودکار باز می‌شود (http://localhost:8787). اگر نشد، خودتان
همین آدرس را در مرورگر بزنید و کلید Enter. در همان صفحه:

- «عنوان» و «متن» را بنویسید و **«ارسال به همه»** را بزنید.
- **تاریخچهٔ ارسال‌ها** (هم در صفحه و هم در فایل ایگنورشدهٔ `tools/.fcm_history.json`).
- **پیشنهادهای کاربران** هم همین‌جا فهرست می‌شود.
- اعلان با **صدای «یادآورها»**، آیکن اپ و رنگ طلایی فرستاده می‌شود.

هیچ وابستگی npm ندارد. اگر پورت 8787 اشغال بود:
`$env:FCM_PORT="9000"; node tools/fcm_server.mjs`

---

## راه ۱ — خط فرمان (بدون باز کردن مرورگر)

```powershell
node tools/send_push.mjs "عنوان اعلان" "متن اعلان"
```

مثال واقعی:

```powershell
node tools/send_push.mjs "نسخه ۱٫۸ آمد" "به‌روزرسانی نصب کنید؛ اذان‌سنج بهتر شده است."
```

پیش‌نیاز (یک‌بار، تا وقتی همین فایل سر جایش است):

- کلید سرویس‌اکانت در `tools/firebase-adminsdk.json` قرار دارد
  (از کنسول → Project settings → Service accounts → Generate new private key).
  اگر این فایل حذف شد، دوباره دانلود و همین اسم را بگذارید.
- اگر کامپیوتر عوض شد: `npm install --no-save firebase-admin` در پوشهٔ `tools/`
  لازم نیست برای ارسال (اسکریپت ارسال وابستگی ندارد) فقط Node نصب باشد.

خروجی: پیام `✓ اعلان به همهٔ کاربران ارسال شد` یعنی تحویل موفق است.

---

## راه ۲ — کنسول Firebase (دستی، بدون کد)

1. https://console.firebase.google.com/project/tawheed-1f347/ → **Messaging** (Notifications)
2. Create first campaign → اعلان اعلان → مخاطب: **topic** و بنویسید `all`
3. بنویسید و بفرستید.

مناسب برای ارسال‌های کم‌تعداد و بررسی فوری.

## چند نکته

- **زمان تحویل**: حدود ۱ ثانیه پس از ارسال؛ اگر گوشی آفلاین باشد، همان لحظهٔ اتصال می‌آید.
- **اپ باز**: اعلان به‌صورت خودکار محلی نمایش داده می‌شود.
- **اپ بسته/پس‌زمینه**: خود سیست‌عامل اعلان را نشان می‌دهد.
- **نصب‌هایی که اپ را باز نکرده‌اند** هنوز در موضوع `all` نیستند و اعلان نمی‌گیرند.
- داشبورد وب (tawheed-1f347.web.app) فقط راهنما و تاریخچه (admin/outbox) را
  نشان می‌دهد؛ ارسال واقعی از راه ۰ یا ۱ یا ۲ انجام می‌شود.

## مدیریت مدیران بعداً

برای افزودن مدیر (مثلاً وقتی ادمین جدیدی با گوگل لاگین کرد):

```powershell
$env:ADMIN_GOOGLE_EMAIL="you@gmail.com"; node tools/admin_bootstrap.mjs
```

این اسکریپت uid را **به `config/app.adminUids` اضافه می‌کند** و هیچ مدیر دیگری
را حذف نمی‌کند (write از نوع arrayUnion است). راه ایمیل/رمز (`ADMIN_EMAIL` +
`ADMIN_PASS`) فقط وقتی لازم است که بخواهید از پنل اپ با رمز وارد شوید؛ رمز باید
منحصربه‌فرد و حداقل ۱۶ نویسی باشد، و اسکریپت رمزِ حساب موجود را هرگز تغییر
نمی‌دهد.

برای برداشتن دسترسی مدیر از یک حساب:

```powershell
node tools/admin_bootstrap.mjs --revoke <email-or-uid>
```

این دستور فقط uid را از لیست خارج می‌کند؛ خود حساب در Firebase Auth باقی
می‌ماند و برای غیرفعال‌کردن یا حذف کامل آن به کنسول Firebase بروید:
**Authentication → Users → حساب مورد نظر → Non-google → Disabled** را روشن کنید
(با این کار کاربر دیگر نمی‌تواند وارد شود، ولی رکورد و سابقه‌اش می‌ماند و با یک
کلیک برمی‌گردد؛ «Delete account» برگشت‌ناپذیر است).

**وضعیت فعلی (۲۰۲۶-۱۰-۱۸):** حساب `admin@tawhid.app` هم از لیست `adminUids`
خارج و هم در Auth **غیرفعال** شد؛ تنها مدیر باقی‌مانده حساب گوگل
`abubakr.f20@gmail.com` است. رمز عبور مدیر در این مخزن وجود ندارد و لازم نیست.
(نام ایمیل گوگل را با متغیر `ADMIN_GOOGLE_EMAIL`، و ایمیل/رمز پنل اپ را با
`ADMIN_EMAIL`/`ADMIN_PASS` می‌توانید تغییر دهید.)
