# آینهٔ قلم مصحف QCF4

این پوشه آینهٔ فایل‌های قلم `quran-qcf4` است تا اپ توحید بتواند خط مصحف را از
هاست خودمان هم بگیرد (اولین منبع در `Qcf4Config.fontBases`).

- منبع اصلی: https://github.com/MohamadHajjRabee/quran-qcf4 (پوشهٔ `fonts/`)
- محتوا: ۴۸ فایل TTF — `QCF4_Hafs_01..47_W.ttf` و `QCF4_QBSML.ttf` (~۹۳ مگابایت)
- مجوز: طبق مخزن اصلی؛ پیش از استفادهٔ تجاری `LICENSE.md` آن مخزن را ببینید.
- بازسازی آینه: بخش «مراحل پرشدن آینه» در `QURAN_CONTENT_HOSTING.md` مخزن اپ توحید.
