## Headline facts

- The app's **spine is already redesigned** (Home, More, Calendar, Splash, Evaluation,
  Quran chrome + lists, bottom nav, settings hub — 125 files import the kit). The debt is
  in the **~34 `D1` legacy screens** and **~30 `D2` partial** ones (§M of doc 00).
- **One real red gate at base:** the 6 failing tests (1 type-scale + 5 home goldens) — wave 0.
- **Two P0-class behaviours are unproven, not broken:** alarm delivery on a real OEM and
  the backup→wipe→restore round trip. A device is attached, so PART 3 can close them.
- **No religious text, fiqh output or mushaf rendering was or will be “fixed” by design
  work**; the four religious/product questions (`F-02`…`F-05`, `U-1`…`U-4`) are listed for
  your decision, not for an agent to decide.

## How to regenerate the numbers

```bash
flutter analyze                       # 192 issues at base
python tools/quality_check.py --strict # 7 gates, must be zero
flutter test                          # 6 reds at base; must be green from wave 0 on
```

The marker table in doc 00 §0 is regenerated by the loop documented in doc 00 §“Method”;
wave 0 turns it into `tools/design_consistency.py` so PART 2 can enforce it in CI.
