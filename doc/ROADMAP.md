# نقشهٔ راه توسعهٔ برنامه (Roadmap)

اولویت‌ها بر اساس تأثیر بر تجربهٔ کاربر، امکان‌سنجی فنی و هماهنگی با ماهیت برنامه
(اذکار، اوراد، اوقات شرعی، قرآن) مرتب شده‌اند.

---

## فاز ۱ — قرآنی (اولویت بالا)

| ایده | جزئیات | ارزش |
|---|---|---|
| دانلود جزءبه‌جزء مصحف | به‌جای دانلود یک‌جا، دانلود هر جزء (۲۰ صفحه) جداگانه | کاهش فشار دانلود اولیه |
| نشانک‌گذاری صفحات در مصحف تصویری | نشانک مستقیم روی صفحه با رنگ | تکمیل حلقهٔ مطالعه |
| جستجوی بصری | تایپ آیه → پرش به همان صفحه و هایلایت | یکپارچگی جستجو |
| حالت حفظ (تحفیظ) | برنامه‌ریز حفظ روزانه + آزمون تکرار + تکرار فاصله‌دار | جذب کاربران حافظ قرآن |
| تجوید و ترتیل | نمایش قواعد تجوید روی متن + پخش ترتیل | آموزش |
| تفسیر تعاملی | باز کردن تفسیر با لمس آیه بدون خروج از مصحف | یکپارچگی |

## فاز ۲ — عبادات و اذکار

| ایده | جزئیات | ارزش |
|---|---|---|
| آمار پیشرفت اذکار | نمودار هفتگی/ماهانهٔ هر ذکر (زیرساخت روزانهٔ ختم آماده است) | انگیزه‌بخشی |
| یادآور اذکار صبح/شام | اعلان برنامه‌ریزی‌شده با زمان‌بندی شرعی | استفادهٔ روزانه |
| تسبیح صوتی/حلقه‌ای کامل | صدای دانه، ویبره، شمارندهٔ دورها | لذت استفاده |
| چالش‌ها و مأموریت‌ها | چالش ۳۰ روزهٔ ذکر، نشان (badge) | تعامل |

## فاز ۳ — نماز و اوقات شرعی

| ایده | جزئیات | ارزش |
|---|---|---|
| قبلهٔ واقع‌نمایی (AR) | دوربین گوشی + فلش جهت قبله | تمایز از رقبا |
| تقویم هجری قمری | تقویم ماهانه با مناسبت‌ها و روزهای مهم | کاربردی |
| محاسبهٔ دقیق‌تر اوقات | تنظیمات کامل روش محاسبه (رویت هلال، زاویه و...) | اعتماد کاربر |
| اطلاع‌رسانی هوشمند | اعلان «وقت نماز» + اذان با صداهای منتخب | استفادهٔ روزانه |

## فاز ۴ — ابزارهای شخصی (ادامهٔ بازطراحی)

| ایده | جزئیات | ارزش |
|---|---|---|
| بازطراحی تک‌تک ابزارها | کارها، هزینه‌ها، یادداشت‌ها، یادآورها، دورهٔ ماهانه، ماشین حساب — با الگوی ختم قرآن | یکدستی ظاهر |
| همگام‌سازی ابری (اختیاری) | بکاپ/بازگردانی اذکار، ختم‌ها و تنظیمات | امنیت داده |
| گزارش ماهانهٔ عبادات | خلاصهٔ خودکار عملکرد ماه (نماز، ذکر، ختم) | انگیزه |

## فاز ۵ — ظاهر و تجربهٔ کاربری (UI/UX)

| ایده | جزئیات |
|---|---|
| تم پویا و شخصی‌سازی | تم‌های رنگی بیشتر + انتخاب فونت توسط کاربر (فارسی/عربی) |
| حالت آمولد/قرمز شب | کاهش نور برای مطالعهٔ شب |
| آنبوردینگ معرفی برنامه | معرفی بخش‌ها در اولین اجرا |
| دسترس‌پذیری | اندازهٔ فونت مقیاس‌پذیر، کنتراست AA (قبلاً بخشی انجام شده)، TalkBack |
| انیمیشن‌های نرم‌تر | انتقال‌های صفحه، میکرو-انیمیشن در لیست‌ها |
| طراحی اتمیک | کامپوننت‌های مشترک (کارت، چیپ، هدر) برای یکدستی همهٔ بخش‌ها |

## فاز ۶ — فنی و انتشار

| ایده | جزئیات |
|---|---|
| CI/CD | بیلد و تست خودکار در هر کامیت (GitHub Actions) |
| کاهش حجم APK | حذف دارایی‌های اضافه، استفاده از App Bundle + Dynamic Delivery |
| تست بیشتر | تست ویجت برای همهٔ صفحات اصلی + تست مهاجرت دیتابیس |
| چندزبانه | فارسی + عربی + انگلیسی (ساختار i18n) |
| انتشار و رتبه | صفحهٔ گوگل‌پلی بهینه (اسکرین‌شات، توضیحات)، بازخورد کاربران، به‌روزرسانی منظم |
| عملکرد | پروفایلینگ فریم‌ها، کاهش بازساخت‌ها (rebuild)، بهینه‌سازی SQLite |

---

## پیشنهاد ترتیب اجرا (۹۰ روز)

1. **هفته ۱–۲:** بازطراحی ابزارهای شخصی (کارها ← هزینه‌ها ← یادداشت‌ها) با الگوی ختم قرآن.
2. **هفته ۳–۴:** آمار پیشرفت اذکار + یادآور صبح/شام.
3. **هفته ۵–۶:** دانلود جزءبه‌جزء مصحف + نشانک صفحات.
4. **هفته ۷–۸:** تم‌ها و شخصی‌سازی + تم شب بهتر.
5. **هفته ۹–۱۰:** بکاپ/بازگردانی و چندزبانه.
6. **هفته ۱۱–۱۲:** CI/CD و تست‌های بیشتر + انتشار نسخهٔ جدید.
